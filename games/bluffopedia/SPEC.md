# SPEC: Блефопедия (`bluffopedia`)

> Всё, что не указано, — из `DEFAULT_GAME_CONFIG` и общих правил движка.
> Карточка пришла под рабочим названием «fibbage» — это чужая игра (Jackbox). Делаем оригинальную игру
> жанра «Словарь» / Fictionary под своим именем: свои названия, контент, экраны; без механик, узнаваемых
> только по Fibbage (кнопка «соври за меня», лайки, финальный раунд с множителем, ведущий-персонаж).

## 1. Концепция
- Питч: на экране редкое слово или странный факт с пропуском: «Японское слово «цундоку» означает привычку покупать книги и ___». Каждый тайно пишет правдоподобную выдумку, потом все варианты вместе с правдой перемешиваются — найди правду и не попадись на чужую ложь.
- Социальный момент: «кто это написал?!», гордость за ложь, которая обманула всех, и удивление, что правда звучала безумнее выдумок.
- Жанр: блеф-викторина, салонная игра «Словарь» (Fictionary): пишешь фальшивое определение, голосуешь за настоящее.

## 2. Игроки
- min / max: **3 / 8**. Ролей нет. Хост выбирает паки, число вопросов (5 / 7 / 10) и язык вопросов (ru / kk / en).
- Язык вопросов — один на комнату (`state.lang`): иначе язык выдумки выдал бы автора. По умолчанию — язык интерфейса хоста (его клиент шлёт settings в лобби, пока `lang === ''`).
- Выход посреди раунда: выдумка остаётся в вариантах, голос сохраняется; досрочные условия считаются по подключённым. < 2 подключённых → results (core).
- Вход после старта: нет. Переподключение: клиент шлёт `bluffopedia:hello`, сервер отвечает адресным `bluffopedia:you`.

## 3. Фазы и тайминги
`GameConfig`: minPlayers 3, maxPlayers 8, rounds 7, countdownMs 3000, roundMs **45000** (= стадия `write`), roundEndMs **15000**, idleKickSec **300**. `VOTE_MS = 30000`.

| Фаза | Длительность | Что видит игрок | Что делает сервер | Выход |
|---|---|---|---|---|
| lobby | — | app-shell + паки + вопросов 5/7/10 + язык (хост) | хранит `packs`, `rounds`, `lang` | хост start |
| countdown | 3 с | «Вопрос N из M» | — | таймер |
| round | стадии ниже | см. стадии | стадии через `restartRound(ms)` + `onRoundTimeout` | `endRound()` |
| roundEnd | 15 с | раскрытие: варианты по одному — кто выбрал, чья ложь, правда последней, «+N» | публикует `truthId`, `lies`, `votes` | таймер |
| adBreak | 1.5–30 с | app-shell; межстраничная в каждом перерыве | core | все `core:adDone` |
| results | — | подиум app-shell | — | хост restart |

Стадии round (`state.stage`, таймер стадии = core `phaseEndsAt`):
| Стадия | Длительность | Суть | Досрочно |
|---|---|---|---|
| `write` | 45 с | вопрос с пропуском, поле выдумки (≤ 40 символов), «Готовы k/n»; выдумку можно переписать до конца стадии | все подключённые отправили |
| `vote` | 30 с | перемешанные варианты (правда + выдумки + при нехватке «выдумки игры»), свой вариант недоступен, подсказка за рекламу | все подключённые проголосовали → `endRound` |

Варианты (`buildOptions`): уникальные выдумки (совпадение по `normalizeAnswer` → один вариант, авторы объединяются) + правда; если вариантов < 4 — добиваются `fake` из контента (кроме совпадающих). Перемешать, id `o1..oN` по порядку после перемешивания (id ничего не выдаёт).

## 4. Состояние и сообщения
`BluffState extends CoreState`:
| Поле | Тип schema | Кто видит | Назначение |
|---|---|---|---|
| `packs` | ArraySchema<string> | все | выбранные паки (lobby) |
| `rounds` | number | все | 5/7/10 (lobby) |
| `lang` | string | все | язык вопросов `ru`/`kk`/`en`, `''` — ещё не задан (сервер считает `ru`) |
| `stage` | string | все | `write`/`vote`/`''` |
| `questionId` / `category` | string | все | `"<pack>/<idx>"` и id пака |
| `question` | string | все | текст вопроса на `lang`, ровно один `___` |
| `submitted` / `voted` | ArraySchema<string> | все | кто отправил выдумку / проголосовал (без содержания) |
| `options` | ArraySchema<BluffOption{id,text}> | все, с `vote` | варианты без признака правды и авторов |
| `truthId` | string | все, **только roundEnd** | id правды |
| `lies` | MapSchema<string> | все, только roundEnd | автор → id его варианта |
| `votes` | MapSchema<string> | все, только roundEnd | голосующий → id варианта |

Скрыто в комнате (`RoundSecret`): запись контента (ответ, `alt`, `fake`), выдумки игроков, авторы вариантов, голоса, подсказки.

Клиент → сервер:
| Тип | Payload | Стадии | Валидация |
|---|---|---|---|
| `bluffopedia:settings` | `{ packIds: string[]; rounds: number; lang: string }` | lobby | только хост; 1..4 известных пака, дубли убрать; rounds ∈ {5,7,10}; lang ∈ {ru,kk,en} |
| `bluffopedia:hello` | `{}` | round, roundEnd | ответ `bluffopedia:you` |
| `bluffopedia:lie` | `{ text: string }` | write | `sanitizeAnswer(text, 40)` + `maskProfanity`; пусто → toast `bluff.toast.empty`; совпало с ответом/`alt` по `normalizeAnswer` → toast `bluff.toast.truth`; повтор перезаписывает |
| `bluffopedia:vote` | `{ optionId: string }` | vote | вариант есть и он не свой; повтор перезаписывает |
| `bluffopedia:hint` | `{}` | vote | 1 раз за раунд на игрока; убирает случайный ложный не свой вариант, если после этого остаётся ≥ 1 ложный не свой, иначе toast `bluff.toast.nohint` |

Сервер → клиент (адресно, `sendToPlayer`): `bluffopedia:you` `{ round; lie: string; ownId: string; hintId: string }` — после принятой выдумки, в начале `vote`, после подсказки, на `hello`. Отказы — адресный `core:toast`.

Анти-чит: вопросы и ответы только на сервере (клиентский бандл их не содержит — проверяется тестом); правда и авторы попадают в state только в roundEnd; очки считает сервер. Просмотр рекламы и владение паком сервер проверить не может — принятый риск, подсказка ограничена 1 на раунд.

## 5. Подсчёт очков
- Выбрал правду → **+2**. За каждого, кто выбрал твою выдумку → **+1** (общая выдумка — каждому автору). Выдумка игры (`fake`) очков никому не даёт. Не голосовал / не писал — 0.
- Тай-брейк итогов: равные очки делят место (results app-shell).
- Пример (A, B, C, D): выдумки A «x», B «y», C «x» (слились), D не успел. Голоса: A→y, B→правда, C→y, D→x ⇒ A +1 (D), C +1 (D), B +2 (правда) +2 (A, C) = 4, D 0.
- Чистые функции `shared/`: `buildOptions`, `pickHint`, `scoreRound`, `pickQuestion` (без повторов в партии, все использованы → из всех).

## 6. Контент
- Серверный банк `content/questions/<packId>.json`: `{ "ru": Q[100], "kk": Q[100], "en": Q[100] }`, индекс i — один и тот же факт на трёх языках. `Q = { q: string; a: string; alt: string[]; fake: [string, string] }`, в en дополнительно `src` — источник для проверки фактов.
- 4 пака × 100 = **400 вопросов на язык**: `words` (редкие слова мира) и `facts` (странные факты) — бесплатные; `laws` (законы и традиции), `records` (рекорды и «впервые») — платные.
- Правила: ровно один `___`; ответ ≤ 30 символов; `fake` правдоподобны и неверны; только общеизвестные проверяемые факты (энциклопедии, Книга рекордов), без городских легенд и «дурацких законов» без первоисточника; 0+: без насилия, алкоголя, политики, религиозных споров, страшилок. После генерации — отдельная сверка фактов, сомнительные заменяются.
- `content/{ru,kk,en}.json` — UI `bluff.*`, `bluff.pack.<id>`, `shop.<id>`.

## 8. Монетизационные точки
- Межстраничная: в adBreak, каждый перерыв (дефолт `everyNthBreak: 1`; раунд ~1,5 мин; Яндекс ≥ 60 с — из конфига).
- Rewarded `bluffopedia_hint` → «Подсказка: убрать один ложный вариант» в текущем голосовании. Кнопка скрыта, если `!ctx.ads.canShowRewarded()` или подсказка уже взята.
- Косметика (6, категория `skin`, видит владелец на вариантах ответов и своей выдумке): шрифты `font_typewriter` (печатная машинка), `font_handwritten` (от руки), `font_storybook` (книжный), `font_neon` (неон), `font_poster` (плакат), `font_pixel` (пиксель) — системные стеки шрифтов + CSS-стиль, без внешних загрузок, с кириллицей и казахскими буквами. Превью в магазине — `ProductDef.preview` (E4).
- Платные паки: `pack_bluff_laws`, `pack_bluff_records` + бандл `pack_bluff_all` (`bluffopedia/all`).

## 9. Аналитика
Стандартные — из app-shell. Свои (архитектор добавляет в `events.ts`, E3):
- `lie_fooled_count: { game; round; fooled: number; players: number }` — шлёт клиент автора на roundEnd, если он писал выдумку; `fooled` — сколько игроков выбрали его вариант.
- `pack_selected` (есть) — хост включил пак.

## 10. Доработки движка (packages, не игра)
- E1 core/shared `text.ts` (P1): `sanitizeAnswer(raw, maxGraphemes): string | null`, `normalizeAnswer(s): string` (NFKC, нижний регистр, ё→е, без пунктуации и кавычек, схлопнутые пробелы), `maskProfanity(s): string` (корни ru/kk/en → `***`). `sanitizeChat` тоже маскирует мат — чат во всех играх.
- E2 ui `widgets/answerInput.ts` (P1): поле с счётчиком `n/max`, Enter = отправить, `setValue/setDisabled/focus`.
- E3 analytics (архитектор): `lie_fooled_count`.
- E4 monetization + ui (контракт — архитектор, остальное P1): `ProductDef.preview?: string`; shop/shopFlow показывают его вместо иконки категории.
