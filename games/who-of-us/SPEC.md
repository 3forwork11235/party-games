# SPEC: Кто из нас? (`who-of-us`)

> Всё, что не указано, — из `DEFAULT_GAME_CONFIG` и общих правил движка.

## 1. Концепция
- Питч: на экране вопрос «Кто из нас первым сбежит с необитаемого острова?» — все тайно голосуют за одного из игроков и пытаются угадать, кого выберет большинство.
- Социальный момент: раскрытие результатов с анимацией — смех, споры, «почему я?!».
- Жанр: party-голосование «кто из нас / most likely to».

## 2. Игроки
- min / max: **3 / 10** (контракт `GameConfig.maxPlayers` сейчас помечен «≤ 8» — комментарий, не проверка; архитектор правит на «≤ 10», см. E1).
- Ролей нет. Хост выбирает паки вопросов в лобби.
- Выход посреди раунда: окно реконнекта, голос сохраняется. Ушедший окончательно убирается из целей голосования; поданные за него голоса не учитываются. < 2 подключённых → results (core); < 3 — игра продолжается (не ломаем партию).
- Вход после старта: нет.

## 3. Фазы и тайминги
`GameConfig`: minPlayers 3, maxPlayers 10, rounds **10**, countdownMs 3000, roundMs **20000**, roundEndMs **9000**.

| Фаза | Длительность | Что видит игрок | Что делает сервер | Выход |
|---|---|---|---|---|
| lobby | — | лобби app-shell + выбор паков (хост) / список паков (остальные) | хранит `packs` | хост start |
| countdown | 3 с | «Вопрос N из 10» | при первом раунде собирает колоду из 10 вопросов | таймер |
| round | 20 с | вопрос, сетка игроков (шаг 1 «Твой голос»), затем шаг 2 «За кого проголосует большинство?», счётчик «проголосовали 4/6», кнопка «Пропустить вопрос (реклама)» | принимает голоса, скрыто | таймер / все подключённые подали оба выбора |
| roundEnd | 9 с | раскрытие: столбики голосов растут по одному, лидер(ы) в центре, анимация раскрытия (косметика), «+2 угадали: …» | публикует `tally`, `leaders`, `correct` | таймер |
| adBreak | 1.5–30 с | app-shell; межстраничная — каждый 5-й перерыв (после 5-го вопроса) | core | все `core:adDone` |
| results | — | подиум app-shell + «звания» (кто чаще всех становился лидером) | — | хост restart |

Подфазы round — только клиентские (два шага выбора), сервер видит одно сообщение.

## 4. Состояние и сообщения
`WhoOfUsState extends CoreState`:
| Поле | Тип schema | Кто видит | Назначение |
|---|---|---|---|
| `packs` | ArraySchema<string> | все | выбранные паки (lobby) |
| `questionId` | string | все | `"<packId>/<index>"`, текст клиент берёт из своего языка |
| `voted` | ArraySchema<string> | все | кто уже проголосовал (без цели) |
| `tally` | MapSchema<number> | все, заполняется только в roundEnd | playerId → голосов |
| `leaders` | ArraySchema<string> | все, roundEnd | игрок(и) с максимумом (ничья — несколько) |
| `correct` | ArraySchema<string> | все, roundEnd | угадавшие большинство |
| `leaderCount` | MapSchema<number> | все | сколько раз игрок был лидером (для званий в results) |
| `skipsLeft` | number | все | оставшиеся пропуски на партию (старт 2) |

Сами голоса (`target`, `guess`) хранятся только в приватном `Map` комнаты — анонимность.

Клиент → сервер:
| Тип | Payload | Фазы | Валидация |
|---|---|---|---|
| `who-of-us:packs` | `{ packIds: string[] }` | lobby | только хост; 1..5 известных id; бесплатные всегда допустимы |
| `who-of-us:vote` | `{ target: string; guess: string }` | round | оба — id текущих игроков; можно за себя; повтор перезаписывает |
| `who-of-us:skip` | `{}` | round | `skipsLeft > 0`, ≤ 1 на игрока за партию; новый вопрос, голоса сброшены, таймер раунда перезапущен (E2) |

Сервер → клиент адресных нет. Анти-чит: подсчёт только на сервере; голоса не попадают в state до roundEnd; лимиты — core rate-limit. Владение платным паком и факт просмотра рекламы сервер проверить не может (клиентские SDK) — принятый риск, ограничен лимитами.

## 5. Подсчёт очков
- Угадал лидера (guess ∈ leaders) → **+2**. Ничья: угадал любого из лидеров — засчитано. Нет голосов → никто не получает.
- Тай-брейк итогов: равные очки делят место (results app-shell).
- Пример (A, B, C): голоса A→B, B→B, C→A ⇒ tally B:2, A:1, leaders [B]. Догадки A:B, B:C, C:B ⇒ A+2, C+2, B+0.
- Чистые функции в `shared/scoring.ts`: `tallyVotes`, `findLeaders`, `scoreRound`; `shared/deck.ts`: `buildDeck(packs, count, rnd)` без повторов.

## 6. Контент
- `content/{ru,kk,en}.json` — UI-ключи `whoOfUs.*`, названия паков и товаров (`shop.*`).
- `content/questions/<packId>.json` — `{ "ru": string[60], "kk": string[60], "en": string[60] }`, индексы совпадают между языками.
- Объём: 5 паков × 60 = **300 вопросов на язык**. Бесплатные: `friends`, `family`. Платные: `work`, `absurd`, `party`.
- Только безобидные формулировки 0+; тест: во всех языках по 60 строк в каждом паке, без пустых.

## 7. Экраны
| Экран | Элементы | @party/ui | Свой DOM |
|---|---|---|---|
| Лобби | + блок паков (чекбоксы, замок + «Купить» на платных) | lobby, shopFlow | `client/packs.ts` через E3 |
| Вопрос | вопрос крупно, сетка аватаров 2×5, шаги, счётчик голосов, кнопка пропуска | timer | `client/game.ts`, `client/vote.ts` |
| Раскрытие | столбики, лидер, «+2» угадавшим, эффект | scoreboard (мини) | `client/reveal.ts` через E3 |
| Итоги | подиум + звания | results | — |
- Портрет 360×640: сетка 2 колонки, 10 игроков без скролла страницы. Десктоп 1280×720: 5 колонок.

## 8. Монетизационные точки
- Межстраничная: в adBreak, `everyNthBreak: 5` (переопределение игры, E4); Яндекс-правило ≥ 60 с сохраняется.
- Rewarded `skip_question` → пропуск текущего вопроса для всей комнаты.
- Косметика игры (5): рамки аватара `frame_crown`, `frame_hearts` (новые значения в `FRAMES`); анимации раскрытия `reveal_drumroll`, `reveal_spotlight`, `reveal_fireworks` (категория `effect`, играют у владельца на экране раскрытия). Плюс общие рамки gold/neon/rainbow видны в сетке.
- Платные паки: `pack_wou_work`, `pack_wou_absurd`, `pack_wou_party` (+ `pack_wou_all` — все три со скидкой).

## 9. Аналитика
Стандартные — из app-shell. Свои (архитектор добавляет в `events.ts`, E5):
- `pack_selected: { game; packId; paid: boolean }` — хост включил пак в лобби.
- `question_skipped: { game; round; packId }` — пропуск после rewarded.

## 10. Доработки движка (задачи в packages, не в игре)
- E1 core: комментарий maxPlayers ≤ 10; `FRAMES` + `FRAME_COLORS` — `crown`, `hearts`.
- E2 core: `PartyRoomApi.restartRound()` — заново ставит таймер раунда (`phaseEndsAt`) в фазе round. ✅ сделано архитектором
- E3 ui: в `StartPartyAppOptions` — `mountLobby?` (доп. блок в лобби) и `mountRoundEnd?` (своё раскрытие вместо scoreboard).
- E4 ui/monetization: `catalog?: ProductDef[]` (добавляется к DEFAULT_CATALOG) и `monetization?` (частичное переопределение по площадкам); в `GameContext` — `ads` (canShowRewarded/showRewarded), `entitlements()`, `track()`, `cosmetics()`, `openShop()`.
- E5 analytics: два события выше.
