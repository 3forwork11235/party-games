# SPEC: Шпион (`spy`)

> Всё, что не указано, — из `DEFAULT_GAME_CONFIG` и общих правил движка.

## 1. Концепция
- Питч: все видят одну локацию («Больница 🏥») и свою роль в ней, один игрок — шпион — локацию не знает. По очереди задаёте вопросы: шпион пытается понять, где он, остальные — вычислить шпиона.
- Социальный момент: блеф, двусмысленные вопросы, «а ты точно хирург?», финальное раскрытие.
- Жанр: социальная дедукция «найди лишнего» (вопросы по кругу + голосование).

## 2. Игроки
- min / max: **3 / 8**.
- Роли: каждый раунд сервер назначает шпиона (справедливо: из тех, кто был шпионом реже всех, не тот же, что в прошлом раунде). Остальные получают разные роли из 7 ролей локации.
- Выход посреди раунда: раунд продолжается. Ушёл спрашивающий/отвечающий — ход переходит дальше. Отключённого шпиона можно «вычислить»; если его обвинили, пока он офлайн, последний шанс пропускается. < 2 подключённых → results (core).
- Вход после старта: нет. Переподключение: клиент шлёт `spy:hello`, сервер повторно присылает роль и подсказки.

## 3. Фазы и тайминги
`GameConfig`: minPlayers 3, maxPlayers 8, rounds 5 (хост выбирает 3 / 5 / 8, сервер ставит `totalRounds` в `onGameStart`), countdownMs 3000, roundMs **15000** (= первая стадия), roundEndMs **12000**, idleKickSec **600** (молчаливый игрок в 5-минутном обсуждении не кикается).

| Фаза | Длительность | Что видит игрок | Что делает сервер | Выход |
|---|---|---|---|---|
| lobby | — | app-shell + паки (E6) + число раундов (хост) | хранит `packs`, `rounds` | хост start |
| countdown | 3 с | «Раунд N: раздаём роли» | — | таймер |
| round | стадии ниже | см. стадии | стадии через `restartRound(ms)` + `onRoundTimeout` (E1) | `endRound()` |
| roundEnd | 12 с | раскрытие: шпион, локация, голоса, исход, очки | публикует `spyId`, `locationId`, `votes`, `outcome` | таймер |
| adBreak | 1.5–30 с | app-shell, межстраничная каждый перерыв | core | все `core:adDone` |
| results | — | подиум app-shell | — | хост restart |

Стадии round (`state.stage`, таймер стадии = core `phaseEndsAt`, виден в app-shell):
| Стадия | Длительность | Суть | Досрочно |
|---|---|---|---|
| `roles` | 15 с | карточка роли крупно, кнопка «Понял» | все подключённые нажали «Понял» |
| `discussion` | 300 с | очередь вопросов, поле локаций, кнопки шпиона | > ½ подключённых нажали «Голосовать»; догадка шпиона → `endRound` |
| `voting` | 45 с | все (и шпион) голосуют за одного другого | все подключённые проголосовали |
| `lastChance` | 20 с | только если обвинён шпион и он онлайн: шпион выбирает локацию | догадка → `endRound` |

Обвинённый — строго больше всех голосов; ничья или нет голосов → никто не обвинён.

Очередь вопросов: первый спрашивающий случайный. `askerId` выбирает `targetId` (не себя и не того, кто только что спрашивал его — `lastAskerId`), тот отвечает вслух и жмёт «Ответил» → становится `askerId`. Спрашивающий или хост может «передать ход» следующему по порядку входа.

## 4. Состояние и сообщения
`SpyState extends CoreState`:
| Поле | Тип schema | Кто видит | Назначение |
|---|---|---|---|
| `packs` | ArraySchema<string> | все | выбранные паки (lobby) |
| `rounds` | number | все | выбор хоста 3/5/8 (lobby) |
| `stage` | string | все | `roles`/`discussion`/`voting`/`lastChance`, `''` вне round |
| `board` | ArraySchema<string> | все | 24 id локаций раунда (`"<pack>/<idx>"`), среди них настоящая |
| `askerId` / `targetId` / `lastAskerId` | string | все | очередь вопросов |
| `questions` | number | все | сколько вопросов задано в раунде |
| `seen` | ArraySchema<string> | все | нажали «Понял» (roles) |
| `voteCalls` | ArraySchema<string> | все | хотят голосовать досрочно |
| `voted` | ArraySchema<string> | все | кто проголосовал (без цели) |
| `spyId`, `locationId`, `accusedId`, `guessId`, `outcome` | string | все, **только в roundEnd** | раскрытие |
| `votes` | MapSchema<string> | все, только в roundEnd | voter → target |

Скрытое (приватные поля комнаты): шпион, локация, роли, голоса, подсказки, `spyCount` по игрокам, использованные локации партии.

Клиент → сервер:
| Тип | Payload | Фазы/стадии | Валидация |
|---|---|---|---|
| `spy:settings` | `{ packIds: string[]; rounds: number }` | lobby | только хост; 1..6 известных паков, дубли убрать; rounds ∈ {3,5,8} |
| `spy:hello` | `{}` | round, roundEnd | ответ `spy:role` этому игроку |
| `spy:seen` | `{}` | roles | — |
| `spy:ask` | `{ targetId: string }` | discussion | только `askerId`, `targetId` пуст; цель — подключённый другой игрок ≠ `lastAskerId` (если есть выбор) |
| `spy:answered` | `{}` | discussion | только `targetId` |
| `spy:pass` | `{}` | discussion | `askerId` или хост; ход следующему подключённому |
| `spy:callVote` | `{ on: boolean }` | discussion | — |
| `spy:vote` | `{ targetId: string }` | voting | существующий игрок ≠ себя; повтор перезаписывает |
| `spy:guess` | `{ locationId: string }` | discussion, lastChance | только шпион; id ∈ `board`; один раз за раунд |
| `spy:hint` | `{}` | discussion, voting, lastChance | только шпион; ≤ 2 за раунд (2-я — после rewarded на клиенте) |

Сервер → клиент (адресно, `sendToPlayer`):
| Тип | Payload | Кому | Когда |
|---|---|---|---|
| `spy:role` | `{ round; spy: boolean; locationId?: string; roleIndex?: number; crossed: string[]; hintsLeft: number }` | каждому своё | старт раунда, `spy:hello`, после `spy:hint` |

Анти-чит: локация и шпион не попадают в state до roundEnd; голоса скрыты до roundEnd; исход и очки считает только сервер. Просмотр рекламы и владение паком сервер проверить не может (клиентские SDK) — принятый риск, ограничен лимитом 2 подсказки/раунд.

## 5. Подсчёт очков
Исходы (`outcome`): `spy_guessed` (шпион назвал локацию — досрочно или в последний шанс), `spy_wrong` (досрочная догадка неверна), `spy_caught` (обвинён и не угадал / офлайн), `spy_escaped` (обвинён невиновный, ничья, нет голосов).
- «Верное вычисление»: каждый не-шпион, проголосовавший за шпиона, **+1** при любом исходе после голосования.
- `spy_caught`: все не-шпионы **+1** (командная победа). `spy_wrong`: все не-шпионы **+1**.
- `spy_escaped`: шпион **+2**. `spy_guessed`: шпион **+4**.
- Тай-брейк итогов: равные очки делят место (results app-shell).
- Пример (A — шпион, B, C, D): голоса B→A, C→A, D→B, A→B ⇒ ничья A:2/B:2 ⇒ `spy_escaped`: A +2, B +1, C +1, D 0. Если D→A ⇒ A обвинён ⇒ не угадал ⇒ `spy_caught`: B, C, D по +2.
- Чистые функции `shared/`: `pickSpy`, `pickLocation`, `buildBoard`, `assignRoles`, `pickHint`, `findAccused`, `scoreRound`.

## 6. Контент
- `content/locations/<packId>.json`: `{ "emoji": string[20], "ru": string[20][8], "kk": …, "en": … }` — запись = `[название, роль1..роль7]`, индексы совпадают между языками. Id локации `"<packId>/<idx>"`, сервер текст не читает.
- 6 паков × 20 = **120 локаций**, у каждой эмодзи и 7 ролей на ru/kk/en (2 880 строк).
- Бесплатные: `city` (Город), `travel` (Путешествия), `leisure` (Досуг). Платные: `movies` (Жанры кино), `space` (Космос), `history` (История).
- `content/{ru,kk,en}.json` — UI `spy.*`, `spy.pack.<id>`, товары `shop.<id>`.
- 0+: без войны/оружия, тюрем, баров/казино, ужасов, политики и религии; роли — профессии и посетители, без стереотипов. Тест: 20 записей × 8 непустых строк на язык, уникальные названия внутри языка.

## 8. Монетизационные точки
- Межстраничная: в adBreak, `everyNthBreak: 1` (дефолт; раунды ~6 мин), Яндекс ≥ 60 с — из конфига.
- Rewarded `spy_hint` → 2-я подсказка шпиону в раунде: зачёркивает ещё 6 неверных локаций (1-я подсказка бесплатна). Кнопка скрыта, если `!ctx.ads.canShowRewarded()`.
- Косметика (6, новая категория `skin`, E2): скины карточки роли `skin_dossier`, `skin_noir`, `skin_neon`, `skin_galaxy`, `skin_gold`, `skin_comic` — видит владелец на своей карточке. Общие рамки/цвета ника видны в сетках игроков.
- Платные паки: `pack_spy_movies`, `pack_spy_space`, `pack_spy_history` + `pack_spy_all` (бандл `spy/all`).

## 9. Аналитика
Стандартные — из app-shell. Свои (архитектор добавляет в `events.ts`, E3); шлёт клиент шпиона на roundEnd (одно событие на раунд):
- `spy_won: { game; round; reason: 'guessed' | 'escaped'; players: number }` — шпион победил.
- `location_guessed: { game; round; locationId; correct: boolean; early: boolean }` — шпион назвал локацию.
- `pack_selected` (есть) — хост включил пак.

## 10. Доработки движка (packages, не игра)
- E1 core (архитектор, контракт): `restartRound(ms?: number)` — таймер стадии; хук `onRoundTimeout?(): boolean` — `true` = игра продолжила раунд, иначе core завершает раунд. Тесты — P1.
- E2 core + monetization (архитектор, контракт): `Cosmetics.skin?`, `CosmeticCategory` += `'skin'`.
- E3 analytics (архитектор): `spy_won`, `location_guessed`.
- E4 ui (P1): слот `skin` в `app-shell/cosmetics.ts` + превью в shopFlow; таймер `m:ss` при ≥ 60 с.
- E5 monetization (P1): `ownedPacks(ent, game, packs)` с бандлом `<game>/all` — общий вместо копии в who-of-us.
- E6 ui (P1): `createPackPicker` — блок паков в лобби (хост — чекбоксы, 🔒 + «Купить», остальные — список); who-of-us переводится на E5/E6.
