# Чек-лист публикации

Перед любым релизом: `pnpm lint && pnpm test && pnpm build`, полный цикл игры на двух реальных телефонах, проверка на прод-сервере (`wss://<API_DOMAIN>`, `/health` отвечает).

## Общее
- [ ] `VITE_SERVER_URL=wss://<API_DOMAIN>` задан в сборке; сервер на VPS обновлён (`docker compose up -d --build`)
- [ ] Версия в `games/<slug>/package.json` увеличена, CHANGELOG/заметка к релизу
- [ ] Все тексты есть в ru / kk / en, ни одного голого ключа на экране
- [ ] Портрет телефона и десктоп; нет горизонтального скролла, тач-цели ≥ 48px
- [ ] Звук выключается при сворачивании вкладки (`visibilitychange`) и на время рекламы
- [ ] Обрыв сети на 10–30 с → игрок возвращается с очками
- [ ] Чат: работает лимит флуда; нет ссылок/внешних контактов в UI
- [ ] Аналитика: в консоли/кабинете видны game_start, round_end, game_end, ad_shown

## Яндекс Игры
- [ ] `pnpm build:yandex <slug> && pnpm zip:yandex <slug>`; `index.html` в корне архива, все пути относительные, архив < 100 МБ
- [ ] SDK подключён как `<script src="/sdk.js">`, `YaGames.init()` до любых вызовов
- [ ] `LoadingAPI.ready()` вызывается, когда игра готова к взаимодействию (`gameReady()`)
- [ ] `GameplayAPI.start/stop` размечают геймплей; stop на паузах, рекламе, меню
- [ ] Межстраничная реклама только в логических паузах (между раундами), не чаще 60 с; только через SDK, сторонние рекламные сети запрещены
- [ ] Rewarded только по явному действию игрока, награда выдаётся в `onRewarded`
- [ ] На время рекламы игра на паузе и без звука
- [ ] Покупки через `ysdk.getPayments()`; товары заведены в консоли с теми же id, что в `catalog.ts`; `getPurchases()` проверяется при старте; расходуемые подтверждаются `consumePurchase`
- [ ] Нет обязательной авторизации; гость может играть
- [ ] Язык берётся из `ysdk.environment.i18n.lang`; в консоли заявлены только ru/kk/en
- [ ] Нет ссылок на другие площадки, сторы, соцсети и внешние сайты; приглашение — ссылка на игру в Яндексе (`?payload=`)
- [ ] Нет системного контекстного меню, выделения текста, скролла страницы на мобильных
- [ ] Игра запускается внутри iframe черновика Яндекса; WebSocket до `<API_DOMAIN>` проходит (wss, валидный сертификат, CORS)
- [ ] Материалы: иконка 512×512, обложка 800×470, скриншоты (портрет и/или альбом), описание и инструкция на всех языках, возрастной рейтинг, пометка «мультиплеер»
- [ ] Черновик проверен в режиме отладки `?debug=1`, отправлен на модерацию

## Telegram Mini App
- [ ] Бот создан в @BotFather, `/newapp` → Mini App с short name; URL = `https://<PLAY_DOMAIN>/<slug>/` (https обязателен)
- [ ] Сборка `pnpm build:telegram <slug>` с `VITE_TG_BOT`, `VITE_TG_APP`, `VITE_API_URL`; выложена в `dist/web` на сервере (Caddy)
- [ ] Подключён `telegram-web-app.js`; `WebApp.ready()`, `expand()`, вертикальные свайпы отключены во время игры
- [ ] Цвета берутся из themeParams/наша тёмная тема читаема и в светлой теме Telegram; учтены safe-area и `viewportStableHeight`
- [ ] `BackButton` ведёт назад по экранам, в лобби закрывает с подтверждением (`enableClosingConfirmation` во время игры)
- [ ] Приглашение: `https://t.me/<bot>/<app>?startapp=<CODE>` открывает нужную комнату (`start_param`)
- [ ] Цифровые товары продаются только за Stars: `createInvoiceLink`, `currency: 'XTR'`, пустой `provider_token`
- [ ] На сервере задан `TELEGRAM_BOT_TOKEN`; webhook бота указывает на `https://<API_DOMAIN>/api/tg/webhook`; `pre_checkout_query` отвечает < 10 с
- [ ] `initData` проверяется по HMAC на сервере для каждой покупки
- [ ] У бота есть команды `/terms` и `/paysupport` (обязательны для оплат в Stars); возвраты через `refundStarPayment`
- [ ] Межстраничная реклама отключена в конфиге (нет провайдера); игра не показывает пустые рекламные паузы
- [ ] Проверено в Telegram на iOS, Android и Desktop
